# Grok Bot CLI

先读随技能携带的[接入教程](references/connection.md)。已有 MCP 时先确认当前工具确实可用。使用终端时优先复用本地已装的 `gbot` 或 knowledge 同仓的启动器。定位并核对目标 Bot 及账号，重名时按返回 ID 核实。读状态和发消息分别按本次授权执行。

验证要区分帮助正常、认证与名单可用、服务接收消息、Bot 实际回复。只发送一次，后续从同一会话读取。发送结果不明先回读，避免重复触发。总结时给出实际看到的结果、哪一段未验证和仍有的故障，凭据只由本机登录管理。
