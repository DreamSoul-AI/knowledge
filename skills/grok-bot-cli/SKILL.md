# Grok Bot CLI

先读随技能携带的[接入教程](references/connection.md)。本次明确指定的 MCP 或运行入口优先。从本次要求或明确的本机配置定位已验证的入口，核对文件、依赖、版本、运行方式、能力范围及证据。适合本次操作且仍有效时优先复用，不能因全局命令更熟悉而退回已知故障入口。未配置、已失效或能力不匹配时，再沿普通 CLI 或已加载且确实可用的 MCP 诊断，保留具体缺口。

定位并核对目标 Bot 及账号。名单、数字 ID 或 agent UUID、会话读取、授权发送和实际回复分别核对，不能把名单成功当作会话可读，也不能将不同接口的标识互换。配置入口可能有额外环境变量或固定回读范围，不能仅凭表面命令判断它会读还是会发。个人路径、账号与目标标识从使用者配置取得，不写入共用说明。在用副本及依赖即使位于临时目录，也不在未迁移核验前清理。

验证要区分帮助正常、认证与名单可用、服务接收消息、Bot 实际回复。只发送一次，后续从同一会话读取。发送结果不明先回读，避免重复触发。总结时给出实际看到的结果、哪一段未验证和仍有的故障，凭据只由本机登录管理。
