# 刷新工作区 conversation-refresh

规则、目录或项目入口更新后，可说“用 $conversation-refresh 重读当前工作区并告诉我变化”。技能会检查实际cwd，读取适用AGENTS/override、REPO、所需USER及已存在的必要记忆或资料入口，说明对本轮工作的影响和断点。

正常刷新直接按 `SKILL.md` 执行。首次准备、异常或缺少操作细节时再进入本说明，不惯例同时载入中英文两份重复内容。必要规则正文保留完整，不靠缩写规范来少读。

需要批量刷新时，明确指定对话及本次变化。先比较变更文件/版本、各目标实际工作区/关联入口与上次可靠读取回执，区分需要刷新、已当前、不受影响、待接续再刷和信息待核。hash 或修改时间不能证明模型读过规则，也不为筛选全文盘点全部对话。

首次使用、切换 cwd/入口或基线不可靠时读必要完整入口；有可信基线时补读相关变化和引用。请求只附具体变化入口及必要线索，目标短回报实际路径、版本、应用与缺口。主对话核对必要工具依据，复用有效回执，不重复改写规则全文。

文件及关系已确定时，可按工具能力合并读取互不依赖的必要文件，保留文件名和各自错误，减少小文件逐个往返。未知入口先定位，有依赖的发现步骤继续顺序执行，不省略必要正文或首次完整读取。

明确要求某个暂停对话现在只读刷新时仍执行，业务继续暂停；没有即时要求时可留到接续再刷。各目标必须自行读取，请求方统一核对。只查看状态不发送刷新消息，发出、读取和实际应用分别汇报。验收先看该刷的是否识别、不该刷的是否未发送；再看发送指令是否只留技能入口、本次变化和必要差异。正常读取 AGENTS.md 等必要正文不属于指令冗长，不为压缩指令而省略。

短请求示例：“按 $conversation-refresh 刷新；变更：<文件/版本>。仅刷新规则，保留业务状态，简短回报。”未安装时用可读的完整 SKILL.md 路径替换调用名，不再重复技能步骤。不设固定字数，以必要信息齐全、没有重复为准。

刷新不是恢复任务。已有暂停、授权和未提交内容保留，不重启宿主、不清空上下文、不创建Hook或记忆系统。工具不可用、路径缺失或权限拒绝时说明具体缺口，不把未读取对象写成完成。安装前须保留完整技能目录；本地候选不代表已发布或自动发现。
