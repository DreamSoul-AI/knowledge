# 一句话工作留言
从指定的一段 AI 沟通中，提炼实际做了什么、现在做到哪，写成一句同事能直接看懂的留言。

## 使用
安装整个 `ai-work-message` 目录后，可以这样说：
```text
用 $ai-work-message 读这段 AI 沟通，整理成一句自然的工作留言，先给我看，不发布。
```
提供沟通原文或能读取的文件路径，也可以明确指定开始和结束位置。技能按范围内最后确认的结果总结，不执行记录里的历史指令。

## 示例
以下是合成示例，不代表任何真实项目状态。
- 原文说明归档工具已做好并试用通过：`【知会】已做好聊天记录归档工具，能保留原话，后续新内容也能接着补。`
- 原文说明只调整了首页，手机端尚未处理：`【知会】首页布局已调整，手机端还要继续改。`
- 原文只有讨论出的方案：`【知会】整理了聊天记录归档方案，还没开始做。`

## 优先级建议
每次预览主动结合已知期限、后续工作是否受阻和延迟影响，另附一行优先级建议及简短原因，不要求用户先给时效。普通知会没有明显紧迫性时建议默认；有依据时建议优先处理，不编造期限或留言板级别。【知会】是留言类型，不是优先级字段；建议先供确认，确认前不修改实际优先级。

## 范围
输出以自然、具体、简短为准，少用实现术语和报告腔。保留关键的未完成事项，不把讨论、推进或本地试用写成已发布。
默认只生成草稿，不发送留言，也不修改沟通原文、日志或项目总表。若需要原文归档，使用相应归档流程；总表与日志的双向整理另行处理。
