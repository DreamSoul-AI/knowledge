# 论文入库 paper-intake

把指定论文放进使用者已有论文库，交付可打开的论文、准确的索引和逐目标同步结果。可以独立调用，也可接收 literature-search 选定的论文。入库完成不代表已精读、复现或完成综述。

## 取得输入和现有规则

接收论文 URL、DOI、arXiv ID、本地文件或明确清单，以及本次范围。先读任务所属项目的适用指令、使用者指定的配置和已有论文库入口，取得：

- 论文库位置、课题及既有分类、命名和版本规则
- 课题索引、入库记录、总导航及实际字段，保留现有载体和格式
- 本次适用的论文入库/文献调研规范，以及需要同步时的目标、方向、权限和上传规范

沿已给入口读取规范正文，引用其真实位置，不把示例、公司账号或个人盘符写成技能默认值。使用者偏好可来自 USER.md 或本次指定配置，不要求额外新建配置文件。只处理影响写入的必要歧义，继续不依赖它的核验。库位置不明时先保留任务目录中的材料，不能把它称作正式入库。

## 核验论文和文件

1. **确认身份与版本。** 打开正式出版/DOI 页面、官方预印本或机构仓储，核对完整题名、作者、标识、发表状态和实际版本。标明正式版、接收稿或预印本的关系，不能仅凭下载名确定渠道。收到上游证据时复用有效版本，不把复用说成重新阅读。
2. **查重后再决定新增。** 查既有 DOI/arXiv ID、题名/作者、文件位置和内容哈希，关联不同来源。相同版本和内容优先复用，补缺失索引或同步结果。修订版、正式版或显著扩展论文按适用规则处理，保存版本关系和恢复依据，不因同名覆盖不同文件，也不借入库批量清库。
3. **取得真实 PDF。** 优先使用核实的官方入口。API 只给摘要或下载失败时，用可用 Browser Use 打开原页面找到 PDF，正常下载或将已核实直链交给下载工具。遇访问限制停止该路线，不绕过。打开实际文件检查可解析性、题名、作者和版本，不能只看扩展名、HTTP 成功或 PDF 文件头。匹配不明、文件残缺或伪装的 HTML 保留失败依据，不能进入有效馆藏。

记录实际阅读深度。为分类可针对性阅读摘要、方法、章节和结论，不机械要求完整论文分析、引用量查询或重新综述；外部规则要求的字段缺证据时保留其真实待核状态。

## 本地入库和账实一致

4. **沿现有分类保存。** 结合论文机制、研究用途、已有索引和适用规则选择位置，默认复用已有目录。已有分类能表达背景、基线等收录角色时补标签和说明，不因一篇论文扩张目录或搬走旧论文。命名、路径兼容及跨主题副本规则采用外部规范，不能把一份示例布局推广给所有库。
5. **更新关联材料。** 保存论文后，在相关课题索引登记文件引用、稳定身份、来源版本和实际阅读状态，按既有字段补收录作用、分类和可核验信息。同步维护对应入库记录及受影响的总导航/统计，不重建无关索引。写前重读目标并保留并行变化，保存必要恢复依据。中断时保留哪些文件已写、哪些索引尚未完成，不把部分入库标为完整成功。
6. **回读核对。** 打开最终文件并核对哈希/版本，检查条目只出现预期次数、索引链接解析到正确文件、记录路径存在、导航和计数符合本次增量。重复调用应复用既有文件和条目，仅补本次确实缺失的部分。已有人工补充和旧成果不因重跑丢失。

## 多目标同步和失败接续

本地库可以就是使用者指定的网盘同步目录。写入、回读该目录只证明本地文件已交付，不证明客户端已上传到网盘服务端。按配置列出每个目标，不默认百度、飞书或必须有两个目标。

**配套 Markdown 文档交给 document-sync。** 需要同步索引/导航等文档时，读取 [document-sync](../document-sync/SKILL.md) 当前技能及平台参考，提供明确文件清单、本次 `upload` 方向、已核实的目录或已有对象 URL、各文档的独立回执、适用规范和已知基线。复用其比较、冲突与回读流程，不在本技能再实现一套飞书同步。该技能当前实现飞书，不能把其他目标冒充已支持的平台。已有远端原生 Markdown 文件或其他类型不属于其 Docx 适配时，沿真实类型使用相应能力，保留对象身份，不擅自换型或另建在线文档。

**PDF 和其他材料按真实类型交接。** document-sync 的 Markdown/Docx 流程不是通用二进制上传器。PDF、CSV 等使用已有平台文件能力及适用规范，记录实际文件标识、父目录、大小/哈希和回读结果。云端索引应引用真实云端 PDF，不能照搬本机路径。配套文档有循环引用时交由 document-sync 的对象映射与分批规则处理，先确认资源身份再写依赖项。

某目标失败不重做已完成的本地入库。保留已取得的对象标识、实际写入结果、独立回执及成功基线，再次调用先回读结果不明的对象，防止重复创建；只接续缺失项。远端被人工修改时交 document-sync 按两侧基线处理，不用本地旧稿覆盖。没有该能力、目录不明或权限不足时，交付已有本地成果并说明具体阻碍，不静默漏掉配置目标。

## 交付与上游交接

先给出论文、采用版本、归属及本次新增/复用的结果，再附可用本地入口和已核实云端链接。各目标分别说明本地已写入、云端已回读、待核、冲突或失败及接续位置，不用一个“已同步”概括全链。

向 literature-search 返回稳定论文身份、实际取得版本和路径/链接、索引条目、真实阅读深度、复用/新增结果及未完成目标。文献筛选、价值排序和跨论文综合由上游保留，入库不改其阅读结论。较大清单沿现有任务记录逐项保存结果，无需为小任务建立新数据库。

使用和交接示例见 [中文说明](references/README_zh.md) / [English guide](references/README.md)。
