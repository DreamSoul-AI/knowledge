# 论文入库 paper-intake

[English](README.md) | 中文

# 一、用途

给定一篇论文或明确清单，将其核验后收入已有论文库。成果包括可打开的论文、正确的分类和索引、入库记录，以及本次授权内的同步结果。不会因为收到一个论文链接就开展全领域综述或全库重排。

**已有流程优先。** 使用者的库位置、命名、分类、渠道表和索引格式来自项目规则、指定配置及现有论文库。技能负责执行和核验，不替这些规则重新起一套名字。既有库的必要信息不全时，先补查入口，只有确实影响写入的歧义才向使用者确认。

# 二、如何调用

可以直接给出：

> 用 paper-intake 将这篇论文入库，按当前项目配置处理。本地先完成，云端按已有同步配置接续。若同一版本已经在库中，复用它并补缺项。返回论文和索引入口、实际阅读状态及各目标结果。

本次只要求本地时说明即可。希望同步的目标、文件范围和方向要与本次授权一致。个人的网盘位置和云端目录留在个人配置中，不写入共用技能。

由 literature-search 调用时，上游传入已经选定的论文、来源/版本证据、实际阅读状态、课题用途和既有记录。paper-intake 返回稳定论文身份、实际文件版本、位置/链接、索引条目、入库和同步状态。无需重新搜索整片领域或把一次入库升级为精读。

# 三、一次入库怎样完成

**核对论文。** 将论文页、DOI/arXiv ID、作者、发表状态与实际 PDF 对起来。通过官方入口下载，必要时用 Browser Use 找到可访问 PDF。打开文件检查正文与版本，避免把登录页、HTML 或另一篇论文当成有效文件。

**先查已有成果。** 标识、题名/作者和哈希配合判断。文件名不同可能仍是同一论文，相同标题也可能是不同工作。相同版本优先复用，正式版和预印本按已有规则关联。需要替换旧版时保留恢复依据与版本变化，不能顺便删除旧研究材料。

**按既有结构收录。** 分类应依据论文机制及收录用途，已有父类能够表达时不为了一个新词另拆目录。文件名和路径长度按本库规则核对，元数据不足不猜年份、渠道和排名。实际略读、仅看摘要、精读或未复现分别记录。

**文件和索引一起核对。** 写入后检查课题条目、入库记录、受影响的总入口和计数。必要的阅读字段按既有格式填写，不把所有字段塞进一张宽表。PDF 落盘但索引没写完属于部分完成。重复运行只修复缺项，不增加同版本副本或重复条目。

# 四、多目标交接

一份任务可以包含本地库、网盘同步目录和云文档等不同目标。目标数量不是固定要求。以下仅是接口示例，不是必须新建的配置文件：

| **材料** | **交给谁** | **核验依据** |
|---|---|---|
| 本地 PDF | 当前入库流程 | 实际路径、身份、哈希 |
| 同步目录中的材料 | 本地文件操作/已有客户端 | 本地回读、可得的客户端状态 |
| 飞书 PDF、CSV | 平台文件能力 | 对象与目录、文件回读 |
| 配套 Markdown → 在线文档 | document-sync | 独立配对、基线、云端回读 |

**document-sync 的输入。** 提供明确 Markdown 清单、`upload` 方向、现有对象完整 URL 或精确目录映射、每份文档独立的 receipt，以及本次适用的上传/排版规范。既有配对和基线沿用，配置路径按该技能解析，不依赖当前终端目录。返回其真实状态和链接，不把状态判断脚本说成执行了传输。

**真实对象类型。** 如果云端索引原来是原生 Markdown 文件、CSV 或其他载体，先读现状，沿其类型更新。document-sync 当前是 Markdown 与 Docx 配对，不能直接覆盖原生文件或未经确认换型。没有兼容适配时保留本地结果，返回明确接续事项，而不是另建同名副本。

**百度等同步目录。** 文件写入配置的本地网盘目录后，给出可打开的本地入口。没有客户端或服务端证据时说明“同步目录已写入，网盘云端未核验”，无需为生成公开链接而改变分享范围。当前 document-sync 只实现飞书，网盘客户端的独立同步不等于新增了它的百度适配。

# 五、部分完成如何接续

例如 PDF、本地索引和记录已完成，飞书 PDF 已有对象 ID，但配套在线索引上传后没有拿到回执：

1. 保留本地成果和已知对象 ID，不重新下载、另存同版本或重建云端 PDF
2. 接续时先读取该云端索引，核对位置、版本和内容，确认上次到底写入了什么
3. 已成功的项目复用，只处理未成功项。两侧都变时保留冲突，交 document-sync 比较，不覆盖人工编辑
4. 结果按目标报告，真实回读后才推进成功基线

失去访问、遇到验证码、下载失败、目标缺失、内容冲突是不同阻碍，应指出受影响项。能够独立完成的本地工作继续，不能为了让整体状态看起来成功而漏掉失败目标。

# 六、交付示例

> 本地已入库，采用指定预印本 v2，归入现有主题。PDF、课题索引和入库记录已回读，重跑复用了原条目。网盘同步目录已写入，云端未核验。飞书 PDF 已核实，配套索引因权限不足仍待同步，已保留目标和回执，下次从该项接续。阅读状态为略读，未复现。

实际回复附真实文件入口和已核实链接。没有发生的动作、打不开的目标和未检查的云端状态不能写成完成。该示例展示状态拆分，不固定所有任务的结论或目标。
