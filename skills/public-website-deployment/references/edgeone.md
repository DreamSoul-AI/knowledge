# EdgeOne Makers 旧配置兼容

仅在本次明确指定 EdgeOne，或已核验的旧配置选择它时读取；china 或 both 本身不触发本流程，新配置的国内路线默认使用 ESA。使用统一 CONFIG.md 中的 edgeone.* 字段，执行前按[配置规则](configuration.md)解析并核验。首版面向国内短时演示；用户要求跨天固定入口时说明备案自定义域名缺口，不能用短时链接冒充完成。

## 控制台发布与刷新

1. 打开[中国站 Makers 控制台](https://console.cloud.tencent.com/edgeone/makers)，核对完整实际 UIN、目标项目和权限，不能只看昵称或尾号。账号站点与加速区域分别确认；国内仅使用中国大陆或包含大陆的项目区域。
2. 新建选择“创建项目 → 直接上传”，使用本次明确名称和区域；同名对象先读取，不能静默覆盖或自动改名。默认已有项目 ID 不参与新建。目录、ZIP、HTML 支持与单文件限制以当前[直接上传规则](https://edgeone.ai/document/173731777484574720)和实际页面为准，不通过删除必需文件凑配额。
3. 更新进入原项目 ID，核对名称、区域和直接上传类型，选择“新建部署”，确认 production 或 preview 并上传整个站点快照，不改变账号、区域或默认项目。操作未知先查部署记录，不重复提交。
4. 等待真实成功状态，读回项目 ID、部署 ID、环境和结果；只凭出现网址不能判定成功。更新后在项目概览取得生产入口并验证新版本，而非只看本次部署专属网址。
5. 点击“预览”，取得平台实际生成的完整 HTTPS 链接及查询参数，不从跳转后的地址栏复制裸域名。

仅刷新预览链接时，核对原账户与项目后点击“预览”取得新链接并验证，不重传产物、不创建部署或改 DNS。访客匿名预览与 CLI 的 --anonymous 匿名部署不同，本流程使用账户内既有项目。

控制台能力不适用且本次选择已有 CLI 时才读[EdgeOne CLI](edgeone-cli.md)，不为一次上传强制生成 Token。真实登录、注册与必要验证码由用户完成；不读取浏览器凭据或调用未核实后台接口。

## 访客验证

本项目实测完整入口先返回 302，签发临时访客 Cookie 后跳转到裸域名。以空白 Cookie 会话从完整链接进入，再检查页面、版本、HTTPS、资源、交互与子页刷新；不附带腾讯云登录 Cookie。无参数、无临时 Cookie 的裸地址返回 401，不据此认定部署失败；完整链接失败时分别核对期限、参数、平台和网络。

预览 HTML 可能增加平台官方演示脚本。资源比对遇到差异要检查实际变更，仅在已识别差异后明确记录，不以任意删除 script 的方式掩盖问题。浏览器和 HTTP 结果不一致时分别记录，无三网证据不声称所有大陆网络可达。

## 链接交付

每次新建、更新、恢复或刷新后的最终回复必须同时包含：

1. **完整链接**：靠前给出实际生成且已验证的完整可点击 HTTPS 地址，保留 eo_token、eo_time 及其他实际参数；不用裸域名、重定向后的地址或省略号替代。未取得或未通过验证时如实报告。
2. **有效期**：注明有效时长、生成日期时间、到期日期时间及用户时区。大陆默认预览按当前[域名规则](https://pages.edgeone.ai/zh/document/domain-overview)为 3 小时，以平台实际提示为准；未给出明确到期值时计算并标为“预计”，从生成时刻而非首次点击计时。
3. **分享提醒**：紧邻链接写明：“转发请复制本消息中的完整链接，保留问号后的校验参数；不要复制打开网页后的地址栏，否则新访客可能遇到 401。”

附实际检查结果、未覆盖范围和项目／部署控制台入口。临时校验参数仅供本次访客交付，不写入 Skill、源码或长期共享记录。

## 恢复与范围

用户要求恢复时，核对原账户、项目及上一份完整可用产物，重发该产物后验证生产入口版本。不要编造 rollback 命令或删除项目；更新／恢复不保证历史部署和缓存立即不可访问。国内长期域名、备案、DNS、套餐、后端与自动化凭据另按用户实际请求处理。
