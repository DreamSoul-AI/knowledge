# 收尾 wrap-up

用于一个对话的一轮收尾。回答本轮做到哪里、能否停及下次从哪里继续，不要求整个项目完成。

## 使用

安装时保留完整的 `wrap-up` 目录。可直接说：

```text
用 $wrap-up 收尾这轮工作。已有总结直接复用，说明本轮结果、未完事项、我是否还需要处理什么，以及下次入口。
```

默认先看当前状态，列出哪些可以结束、哪些还不能及原因和建议，不主动补做尾项或修改工作状态。明确要求执行收尾时按已确认范围推进；本轮已经授权的具体动作不用再问。明确要求立即停下时保留断点，不用盘点拖延停止。

## 多个对话

明确要求多个对话时，分别给出判断。例如一个对话已完成本地方案、另一个还有验证在跑，不能统一写成“全部完成”。来源不可取得时如实说明，不推定后台状态。

工作总结、留言、日志、归档和发布按本轮实际需要接入，不是每次收尾都做。技能本身不提供后台执行、定时提醒或新的发布授权。
