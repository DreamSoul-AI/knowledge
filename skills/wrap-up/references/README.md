# wrap-up

Close out one round of work in a conversation: report results, remaining work, whether it can pause, and where to resume. The whole project need not be finished.

## Use

Install the complete `wrap-up` directory, then ask:

```text
Use $wrap-up to close out this round. Reuse the existing summary and report the results, remaining work, anything I need to handle, and the next starting point.
```

By default, inspect and report what can finish, what cannot, why, and the suggested next action. Do not complete remaining steps or change working state merely to produce this inventory. When execution is explicitly requested, follow the agreed scope without asking again for actions already authorized in this round. An immediate stop request takes effect without delaying it for an inventory.

## Multiple conversations

Only combine conversations when requested, and retain each conversation's results, remaining work, pause decision and next entry. One finished conversation does not make every conversation complete. Report unavailable sources and unknown running states honestly.

Summaries, messages, logs, archives and releases are used when the current task needs them, not as mandatory closeout steps. This skill provides no background execution, reminders or additional publication authority.
