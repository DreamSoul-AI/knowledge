# GitHub 汇总

把分散在仓库、分支和指定本地记录中的经验完整接到接收工作区，交付能追溯来源、区分待审与已采用的汇总。仓库运行情况可作为判断依据，但不以一张 PR 或提交数量报表代替经验接收。

## 范围和输出

结合本次请求、项目约定和已有采用记录确定仓库、分支、本地来源、接收目录及允许动作。分支可以明确列出，也可以按用户指定覆盖全部现存分支；列清实际覆盖和排除范围，不从几个样例推广到整个组织。缺项会改变接收方、数据范围或外部动作时集中核对，其余工作继续。

先读取相关 AGENTS.md、REPO.md、适用文档规范，以及接收工作区已有条目。区分汇总工作区和经验最终接收仓库。条目原定接收方按原文、项目语境和明确交接核实，不能因当前对话属于某仓库就把经验全部归给它。

本次只读时，远端仅盘点和读取，获准的本地位置可接收原文、整理候选与清理建议。输出包含实际来源和缺口、完整接收依据、按接收方归并的条目、已采用与待处理状态、尚需确认的问题及下一步。真实仓库操作另按本次范围执行。

## 盘点并完整接收

按[经验汇总规范](references/curation.md)查找项目 Learnings、旧 Experience 及有依据的历史目录，先固定各分支完整顶端 SHA，再按该版本读取。项目约定优先；按路径组成部分发现候选，不用宽泛的 learn 子串将 sklearn 等第三方内容当作经验。自定义来源按实际约定显式补入，不要求改名。

本地接入先枚举所选仓库登记的全部 worktree，从各自根检查未提交和被忽略的经验原文。主仓库的 tmp 排除不能漏掉登记在其中的独立 worktree；缓存、历史快照、其他克隆和不可读目录分别登记边界，不全盘扫描。处理远端分页和树截断，区分无匹配记录、读取失败和未扫描完成。工作树的实际字节是版本，HEAD 只作为基线。

可复用 [接收脚本](scripts/github_summary.py) 的 collect、ingest、restore 和 check-cleanup，参数与验收见[脚本与接续](references/curation.md#六脚本与接续)。它维护原文、来源身份和增量，不自动判断经验价值、接收方或正式采用。已有 Git checkout 可只读盘点；只有远端时用连接器/API固定版本和完整正文，再交给 ingest，不强制另装 GitHub 客户端。

先保存完整原文和可恢复依据，再摘要。为来源保留仓库、分支、完整提交、路径、内容哈希和证据入口；相同内容可共用快照，所有分支身份仍须保留。敏感原文和个人配置遵守本次接收及披露范围，不进入可分发技能。

## 去重、归并和状态

先识别完全相同的原文，再按问题、有效做法、适用条件和证据归并语义重复。名称相似只用于找候选，不丢掉不同方案、负例或适用限制。从已有接收条目增补有效变化，重跑复用同一来源版本，不能每次另建一份汇总。

候选讲清解决什么问题、怎样做、适用于哪里、证据是什么、还没验证什么，并定位应接收的规范、技能或项目文档。逐条判断，不按整个仓库一概排除；同一归档中的新增段落也可能有可复用变化。以来源清单接续相同条目，未变来源复用，修改只核对应条目，路径迁移保留原身份和原去向，不每轮生成同义待办。实际采用需回读正式内容及版本，不能凭“已完成”标签、旧清单或发布计划关闭条目。

同时核对相关 README、目录页、旧路径引用、重复正文及冲突痕迹。原文接收成功不等于入口完整；脚本结果只是定位线索，回到固定版本验证。明确暂不修复的项目只保留检测依据，不另建待修清单或派工。

模板和项目规则的采用更新复用现有 workspace-update 或项目流程，不重新实现 Broadcast。确需检查仓库、PR、CI、分支或部署状态时，按本次问题补查；发现相关待办不等于获准修复、合并或清理。

## 清理和接续

分别判断来源清理与接收方完成项清理，具体条件见[经验汇总规范](references/curation.md#四清理和完成项收尾)。来源要有完整接收和恢复依据，满足其项目额外条件及当前授权后再处理；接收方的候选要在正式采用或完成适用归档并回读后再收尾。

外部修改前重读目标和分支状态，保留并发新增内容。原文快照完整且当前源未变只是清理前置条件，正式采用、持久恢复位置、引用处理和本次授权仍须分别满足。check-cleanup 不执行删除；来源变化、恢复副本损坏或入口不完整时保留原件，先补收再判断。已获授权的同范围清理接续到实际回读，不机械重复申请；仅请求盘点或本地试稿时不写远端。旧清理已经完成时复用结果，不再次删除、重复提 PR 或重做模板分发。

记录实际来源版本、接收位置、归并与采用状态、外部操作结果和剩余项。中断后从已有接收和目标现状继续，结果不明先核实，不清空记录后全量重发。对话里给出成果入口和具体缺口。
