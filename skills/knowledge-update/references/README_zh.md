# 能力更新 knowledge-update

独立检查/更新已经采用的Knowledge技能和工具，保留项目及个人定制。不会默认安装全部技能或升级环境。

```text
用 $knowledge-update 检查这个项目已采用的技能和工具，先给差异预览，不改安装目录。
用 $knowledge-update 更新已采用的能力，沿既有采用记录定位来源和目标，保留定制，核对后报告。
```

可传本次模式、项目位置、已有采用清单、固定来源版本、排除项及需保留内容；已有记录足够时直接复用，不要求重新填写配置表。检查模式不写目标，更新模式在实际授权内完成。

安装保留完整knowledge-update目录。它可独立使用，也由workspace-update默认接入。一次更新共用来源、范围和结果，已完成的目标不再处理；同版本无新增差异就无需变更。

报告分清来源版、实际目标版、保留定制、排除、冲突/失败、验证及重载说明。文件更新不等于运行器已发现或实际任务已经调用。

个人技能可沿本人已确认的username分支采用，通用技能仍沿各自正式来源。按条目固定提交，不用个人分支继承的通用旧版覆盖当前安装，也不默认把个人技能合回通用分支。个人日志等草稿只有审阅状态时，不能当成已安装或已发布。
