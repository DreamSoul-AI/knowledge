# Agent 实验执行

把“你试一下这个到底怎么工作”变成实际可观察的实验。适用于不同Agent环境中的机制探测、提示词或配置效果、工具行为和工作方法验证。Agent 选择合适的方法并跑完，不要求使用者先写实验方案，也不要求使用Codex。

## 使用

安装整个 `agent-experiment` 目录，保留 `SKILL.md`、`agents/` 和 `references/`。已有登录和相关工具权限需由实际环境提供。

```text
用 $agent-experiment 验证批量操作中断后重跑会不会重复处理，只用本地合成材料，不连接真实业务平台，给我结论和依据。
```

也可以提供已有材料、目标界面、允许的操作和预算。Agent 只补问影响执行的关键信息，自主选择直接探测、前后比较或分组实验；需要独立上下文时使用隔离测试会话。

## 收到的结果

简单问题直接得到结论、实际观察和适用条件。需要留存复跑时，沿用项目位置保存简短记录、必要证据和脚本。机制、权限、配置失败和模型表现分开解释；CLI 与桌面结论分别取证。

实验默认使用合成材料或允许的输入，不改真实业务内容和持久配置。外部写入、清理或发布仍按本次实际授权执行。有限样本不代表所有模型或场景都成立。

维护者的执行细节见 [执行参考](execution.md)，Codex CLI和App Server只作为按需采用的平台说明。科学课题的完整研究计划使用适用研究流程，技能实现维护则接对应研发流程。
