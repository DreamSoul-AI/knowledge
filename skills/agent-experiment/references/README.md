# Agent Experiment

Turn a short verification question into an executed, observable experiment across available Agent environments. Use for mechanism probes, prompt or configuration effects, tool behavior and working methods. The agent chooses and runs the experiment without requiring the user to supply a protocol or adopt Codex.

## Use

Install the entire `agent-experiment` directory, keeping `SKILL.md`, `agents/` and `references/` together. The actual environment must provide authentication and relevant tools.

```text
Use $agent-experiment to check whether retrying an interrupted batch duplicates completed work. Use synthetic local material, do not connect to business services, and report the evidence and conclusion.
```

Optional inputs include existing material, the target surface, permitted operations and budget. Ask only for consequential missing information. Choose direct probes, before-and-after checks or grouped comparisons as appropriate; use isolated test sessions when independent context matters.

## Results

For a simple question, deliver the conclusion, observations and applicable conditions directly. Save a short record, necessary evidence and scripts in the project's existing location when review or reproduction warrants it. Distinguish mechanism, permission and configuration failures from model performance. Collect CLI and desktop evidence separately.

Use synthetic or permitted inputs and preserve business data and persistent configuration by default. External writes, cleanup and publication remain subject to the current authorization. A limited sample does not establish behavior across every model or setting.

See the [execution reference](execution.md) for conditional technical guidance; Codex CLI and App Server are optional platform-specific paths. Use the applicable research workflow for a full scientific study and the development workflow for maintaining skill implementations.
