# 私有 Git 同步

只将明确选定的正式资料及必要依赖从本地送到配置的私有仓库。它不是隐式双向同步，也不负责删除远端。采用之前先核对实际私有属性、登录身份、分支和项目纳入规则，不能仅因配置写private就认定远端私有。真实USER、凭据、缓存和临时材料不随正式包上传。

1. 固定来源文件及其hash、目标分支commit和上次成功基线。核对allowlist与dependencies及相对链接，目录范围需结合Git忽略和项目纳入边界列成确切文件清单，不用git add -A或强行纳入忽略文件
2. 用独立临时检出读取目标，不切换或清理使用者原工作树。保留原索引、未提交改动和未跟踪文件，不以stash代替保护。写前检查目标仍是固定基线
3. 对每个选定文件做三方比较：上次来源、当前本地、远端。未变来源不回退远端人工修改。目标与源都偏离基线且无法合并时保留冲突，其他明确项继续。没有基线时仅对已确认可新增或可安全判断的条目处理，不直接覆盖已有不同内容
4. 在隔离检出只写核定文件，保留编码/换行与目标忽略要求，检查diff、资源与引用。无实际变化不提交。只暂存明确文件，不能携带用户原索引。提交前再次核对远端head，非快进时停止并补取最新差异，不force push
5. 按已授权分支流程推送并回读固定commit、实际文件内容和必要依赖。按逐文件状态保存成功基线，结果未知先查已知commit再补写。失败不得把未推送或冲突项记为完成

检查模式只读比较，关闭时不检出写入、不提交、不推送。用户已明确选择和授权的常规写入连续执行，不再逐文件重复问。目标仓库、范围或权限确实不明时仅补必要歧义。

配置字段不是伪CLI参数，可由USER、既有采用记录或本次自然语言表达等价输入。组织分发与此路径独立：组织路径仍按github_distribution.enabled、既有清单/排除项、PR检查合并回读处理，不借个人私有同步遍历组织。
