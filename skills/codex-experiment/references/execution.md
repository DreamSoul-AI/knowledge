# Codex 实验执行参考

仅在需要独立会话、运行参数或更细证据时读取。本页给选择依据，具体命令以当前版本帮助和项目允许的执行方式为准。

## 选择执行入口

- **直接工具探测**：文件解析、工具参数和确定性行为优先直接调用，不为工具问题额外启动模型
- **CLI 独立运行**：适合检验启动指令、提示词、配置和文件操作。先读 `codex --version`、`codex exec --help`，固定工作目录，按需使用 `--json`、`--output-last-message` 或 `--output-schema`
- **App Server**：需要同一会话多轮交互、运行时状态或事件边界时采用。先用当前版本的帮助和官方协议核对请求、事件及结束条件，不照抄其他版本消息结构
- **桌面或其他界面**：验证对应界面的功能时在该界面取证。CLI 证据不代替桌面行为，API 能力也不证明 UI 已提供入口

沿用当前已有认证和受控运行方式，不复制登录文件。连接器、网络或沙箱不可用时按实际原因处理，不通过关闭安全机制取得“成功”。

## 隔离和公平比较

独立样本使用新的目录和会话，记录实际工作目录、模型、版本、权限及传入材料。测试读取配置或指令时，用合成标记和最小文件替代真实个人资料；比较时保留变量之外的相同条件。需要延续会话才能验证的功能按真实顺序运行，并说明此前状态。

技能测试要证明目标版本被读取。明确给出技能路径或在隔离测试项目放入完整技能目录，核对执行记录，不仅依赖同名技能已出现在列表。测试 Agent 只收到任务、所需输入和技能，不把预期答案或先前诊断写进待测输入。

对子会话设置有限运行时长和次数。超时先停止当前测试进程并核对其后代进程和未决副作用，保留失败证据，再决定是否重试；不要结束其他任务。环境调整只限本次进程且说明理由，不把一次机器排障写成全平台必需步骤。

## 取证和判读

先列少量可区分的结果，再运行，避免看到输出后修改通过标准。效果比较以用户关心的结果判读，如正确执行、遗漏、必要人工修订和成本；不预设统一分数。

`--json` 的运行事件、最终回复和工具写入的文件是不同证据。需要结构化回答时检查回答符合 schema；需要文件或状态变化时另读实际产物。对照各组实际工具调用和失败记录，避免“说执行了”代替执行。

足以回答问题时收尾。存在竞争解释时增加一个能区分它们的小探测，比无目标重复更有价值。提示词表现等随机结果保留样本限制，不从单例估算整体提升。

## 按需留存

可复跑实验只保留复现所需的任务、输入、命令或脚本、关键配置、结果和判读。沿用项目目录，不固定设备路径或强制文件树。原始事件含个人内容时留在允许范围内，分享去敏摘要和必要片段，避免提交完整私有会话。

报告采用项目适用文档规范。短记录可以直接写问题、做法、观察、结论和限制；大量样本才增加清单或表格，不为格式创建空章节。
