# 工作区更新 Workspace Update

将完整的 `skills/workspace-update/` 目录安装到当前运行器的技能目录，保留 `SKILL.md`、`agents/` 和引用文件。已有安装先比较并保留定制。

使用：`用 $workspace-update 完成本轮已采用项目和配套发布位置的更新，保留项目及个人设置，逐项核对并汇报。`

先从项目已有采用记录和发布配置确定范围与排除项。单项目更新只处理该项目，整轮更新覆盖清单内的仓库、本地、云端及下载包；平台操作使用当前环境可用的工具并遵循已取得的授权。只检查时给预览。
