# 个人日志 personal-log

这是GitHub用户diaoenmao的个人流程，不是所有人的日志规范。保留原流程的转日、年月归档、新日接续、旧日清理和周分隔；实际入口从当前项目USER.md读取，不随技能上传私人日志。

## 安装

```text
$skill-installer
请安装 https://github.com/DreamSoul-AI/knowledge/tree/diaoenmao/skills/personal-log
```

也可复制完整personal-log目录到当前运行器的技能位置；已有同名安装先比较，保留个人改动。发布到个人分支并不会自动安装。本次没有要求安装或处理真实日志。

## 使用

可说“用 $personal-log 只清理指定旧日”“接着我已经手动完成的归档，准备新一天”或明确要求完整转日。技能先读取实际日志和本次要求，避免重复归档或再次推进日期。飞书编辑需要当前环境的lark-doc能力及本人权限，读取入口不等于已获写入授权。

**保留原标记。** 勾选表示当天做过，不等于项目结束。旧日已勾记录保留加粗和原有格式；新日加粗继续项取消勾选，非加粗已勾事项加删除线暂留。只清旧日不改顶部清单；不机械清除旧日加粗。
