# 每日会议总结 Daily Meeting Summary

[English](README.md) | 简体中文

整理已结束会议的原始记录和会议总结，复用已有成果，按确认的配置交付云端。由现有「每日会议总结」的提示词和配置提炼，作为可复用首版维护。实际验证范围见文末。

## 文件

- [提示词](prompt.md) 保存一轮任务的目标、依赖、处理顺序和交付要求
- [配置示例](config.example.yaml) 提供时区、扫描、规则、位置、成果和执行范围的接口

配置供 Agent 阅读，目前没有配置解析器或自动安装器。示例字段属于本任务约定，需要由 Agent 解析成技能所需的实际输入。所有非空占位符和关键空值都要在部署前核对。

## 依赖

1. [日历会议归档 Calendar Meeting Archive](../../skills/calendar-meeting-archive/SKILL.md) 统筹来源、责任、已有稿、分类、增量进度和接续
2. [会议总结 Meeting Minutes](../../skills/meeting-minutes/SKILL.md) 在确需整理时接收原始材料、补充材料、适用规范和现有稿
3. [文档同步 Document Sync](../../skills/document-sync/SKILL.md) 接收明确的成果清单和逐份目标，执行获授权的上传

三个技能的安装目录和版本由实际项目提供。日历、会议材料、飞书文档的读取和写入还需要对应工具与实际用户权限。运行条件沿用对应技能的说明。

## 配置和部署

参考安排为每天 `00:00`、`Asia/Shanghai`，来源于原任务的配置。时间只用于说明计划，复制这些文件不会改变平台任务。配置中的部署启用标记为 `false`，云端写入也为 `false`，实际部署时按本人确认范围填写。

路径以 `project_root` 为基准。项目根、配置文件和每项资料的实际路径由部署者确定。显式指定的规范不可读时，保留受影响步骤及原因。各会议类型的专项规范通过配置匹配，例会和周回顾要求也从这些规范读取。

原任务要求有可用原文且应由本任务处理的会议交付会议记录和会议总结，适用专项建议另行筛选。示例保留这一成果范围，上传则分别核实每类成果的目录和受众。会议记录上传包括经授权的文本原文，录音、视频等附件按具体范围处理。

对已有部署，先核对任务重叠情况，再继承其状态、已知正式稿、逐份配对和成功基线。本包不包含原使用者的项目路径、身份、日历标识、云端目录、旧任务或聊天标识。历史别名和系列映射由实际项目配置提供。

只有计划启用或改动实际调度时，才通过平台确认承载项目、聊天、时区和执行范围。通知偏好由调度平台配置，任务内的结果反馈要求见提示词。

## 接入 Codex 定时任务

任务在调度平台保存一段入口提示，指明本地 `prompt.md` 和实际项目配置的位置。每轮先读取这两份文件，再按配置读取项目规范及三个技能。这样可以在本地维护任务正文，平台只维护入口和调度。

可采用以下入口文字，部署时填写实际路径。

```text
在 <实际项目根目录> 执行本任务。每轮先读取
<本地 knowledge 目录>/automations/daily-meeting-summary/prompt.md
和 <实际项目配置文件>，按当前文件执行本轮已授权流程。
来源不可读时报告缺项，保留已有成果和进度。
结果返回本承载聊天。
```

入口路径只写入使用者的实际任务。接入既有任务时，保留其时间、时区、承载聊天和通知设置，只更新提示词；重新读取确认保存结果。原项目配置可以沿用，提示词按其已有字段读取规范、目录、状态和成果要求，无需复制个人配置进仓库。补充的配置样例分别说明专项规范、补充材料、逐类云端目录及命名入口。

这是一种每轮显式读取文件的接入方式。桌面本地任务需要机器开机、应用运行及目录可读。纯网页任务需要可访问的上传资料或连接服务，部署时按该环境准备任务定义、配置和来源。[官方定时任务说明](https://learn.chatgpt.com/docs/automations?surface=app)
