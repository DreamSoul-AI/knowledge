# 可配置共享资源接入验证

## 环境和边界

Windows，Python 3.13.9，Git 2.56.0.windows.1。测试仅在 knowledge 的 `.local/configurable-shared-resources-tests/` 下创建临时 Git 仓库、资源和真实符号链接，清理前核对临时根归属。没有读取、移动、删除真实资源或替换现有仓库链接，没有更改定时任务。

实现为 [link_shared.py](../../tools/shared-repository-resources/link_shared.py)，测试为 [test_link_shared.py](../../tools/shared-repository-resources/tests/test_link_shared.py)。执行使用现有 Python 和 Git，没有安装依赖。创建符号链接需要当前执行上下文具备系统权限。

## 实际执行

从 knowledge 根目录执行：

```powershell
$env:SHARED_RESOURCES_TEST_ROOT = (Join-Path $PWD '.local/configurable-shared-resources-tests')
$env:SHARED_RESOURCES_TEST_REPORT = (Join-Path $PWD '.local/configurable-shared-resources-tests/results.json')
python -B -X utf8 tools/shared-repository-resources/tests/test_link_shared.py
```

最终16项测试通过，没有跳过，进程退出码为0。逐项结果保存在指定本地 JSON 中。这里的通过只覆盖下列场景，不代表已接入真实项目或其他操作系统。

## 发现和修正

首轮把 Git 的 `--literal-pathspecs` 同时用于 `ls-files` 和 `check-ignore`，后者报告不支持路径 magic，导致创建后的忽略核验失败。修正为仅对 `ls-files` 使用该选项，重新执行后通过。

另针对更具体忽略规则否定根规则的情况，验证工具能报告未生效规则，重跑不重复追加同一行。所有后续改动完成后执行上述完整测试，最终结果为16项通过。
