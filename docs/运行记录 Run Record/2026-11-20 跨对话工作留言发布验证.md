# 跨对话工作留言发布验证

## 实际覆盖

使用两个本人确认的时间窗口完成真实Codex记录盘点、事项归并、现有留言核对和分板试写：一个为近期跨日窗口，另一个为11月17日全天。历史窗口中44个创建时间符合条件的对话读取到边界或可用历史末尾，其中21个有窗口内已完成回合。跨界和未结束回合缺少逐条时间的部分保留不确定性。

真实核对区分了后续完成和当日进度、测试副本和已安装正式版，以及各板分别发布的状态，避免据此误报。另修正了遗漏个人配置中不同板的入口偏好，以及只交付单条样例而未补齐选定目标版本的问题。历史试写可以只有一项新增候选，其他事项保留去重或暂缓原因。

## 本地合成续跑

用两项合成事项、三个合成目标板构成六个交付目标。六个本地用例通过，覆盖部分权限失败、写入已提交但响应丢失、目标提交后本地回执前退出、成功后重跑、人工改稿保护、原成功条目消失、同标题不同事项及损坏的续跑记录。部分情形在同一个用例内联合验证。

最终恢复后每个目标仅写入一次。人工修改和原条目消失保持待核，不覆盖或盲目重建；损坏记录在写入前报错，不清空后重发。模拟载体与脚本仅留本地，不随技能分发，也不作为真实飞书API测试替身宣称已验收。

## 真实写入边界

校准期间曾发生一次发布范围误判，实际写入两条后，本人明确要求撤回。已局部撤回并回读，原有正文、引用与编号恢复；其他板未写入。随后补充了校准阶段、登录授权与发布范围分别判断的要求，并将撤回状态置于原成功回执之后。

这次误写和撤回不算真实批量容错通过。飞书大批量写入、真实限流、超时、并发修改与跨进程恢复仍未验收，后续实际操作继续遵循明确范围、回读和不盲目重试。

## 发布检查

技能结构、YAML、相对链接和差异格式检查通过。发布文件按明确清单核对，个人路径、账号、板标识、原始对话及本地测试输出均排除。GitHub发布和本地安装版一致性分别以发布后的实际核对为准，不能仅凭源文件修改认定安装完成。

发布只更新技能及其使用入口，不发布任何工作留言或改变定时安排。
