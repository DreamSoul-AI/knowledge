# Agent 实验执行发布核对

2026年11月21日，Windows/Python 现有环境。使用完整 agent-experiment 目录，验证范围为现有调用证据核对与一次隔离目录中的直接工具探测，没有清理远端、修改业务表或启动新定时任务。

## 已有调用证据

**实际使用** Grok Bot 对话在北京时间11月21日02:45读取已安装 SKILL.md，随后检查实际入口，完成 Bot 主动消息回到指定 Codex 对话的有限验证。原始工具回执与对话收到的消息分别存在，支持该次路径可行，不证明持续通讯或其他环境稳定可用。

**读取与实验分开** Figma 和 Hook 对话有明确的技能读取记录，但每项结果仍以对应运行证据为准。Hook 脚本的模拟输入成功不能代替产品级 Hook 触发成功。

**早期未成功部分** 此前独立 CLI 任务发现了技能，读取正文时工具遇到 Windows CreateProcessWithLogonW 错误。它支持发现路径，不是独立实验执行成功。本轮不将其改记为通过。

私有会话与完整环境事件留在维护者本地，未附在公开分发中。以上为维护者根据原始记录作出的来源核对，外部读者不能仅凭本页独立复核那些私有回执。

## 本轮有界实际验证

显式读取已安装技能后，以当前来源接收工作为对象，选择直接工具探测，无需再启动模型回合。输入是本次已取得的固定版本资料，写入限制在新的隔离副本。

## 格式和分发核对

Skill Creator 校验采用 python -X utf8。首次不带 UTF-8 模式时，工具受系统默认 GBK 影响而读文件失败；指定本次进程的 UTF-8 模式后校验通过，没有重装环境或修改持久设置。

技能按完整文件集合分发，安装与正式分发内容需要逐文件比较，允许各自保留换行格式。检查指南、元数据和本地引用。Markdown 解析和技能结构检查不代替实际 Agent 行为验证。

## 未验证范围

没有验证多写入者并发、在线来源变化时的清理、真实远端故障恢复、桌面端自动选中技能，或各 Agent 平台的普遍表现。此次直接工具探测不构成新的独立模型盲测，也不用于估算总体成功率。
