# 共用定时定义核对

本轮在隔离检出比较已发布对话技能基线与 dev 差异，按文件清单接入三份已审候选；既有 dev-only testing-system 内容不进入正式发布。当前没有 workflow 文件或已登记 workflow，本轮不新增或手动触发 Actions。

配置核对复用三份定义的两种频率示例，确认调度默认停用、频率/时间/时区留空，非调度字段保留。新加自然日报告仅是可选模式，默认仍增量。日期文字算例覆盖计划时区换算、人工日期优先、延迟不参与归属，以及夏令时下 25 小时自然日；这些是配置和日期运算核对，不是调度器或 Agent 业务实跑。

检查新旧入口的相对链接、兼容提示词转读、conversation-refresh 正式包存在、双语导航和敏感路径。保留旧配置状态、补漏、分页、未完项及手动预览边界；不以换目录重置生产进度。对新自然日 Agent 执行、真实延迟触发、会议/邮件读取、生产游标推进、上传与更新后刷新均未新增平台验证。

发布后分别只读核对两个现有部署位置的新文件是否可读及实际内容是否对应正式版，未准备好时由部署方先同步受影响包，再切换任务引用。没有改实际任务、用户资料或成功游标。具体部署状态由部署环境回执维护，不写入共用包。
