# workspace-sync 有限验证

新增workspace-sync，复用原workspace-update默认本地模板与组织分发流程，保留knowledge-update标识。私有Git同步作为默认关闭的独立选择，规定明确仓库、分支、正式资料及依赖清单、隔离检出、固定基线、局部纳入、冲突保护与推送回读。

2026年11月28日，在合成本地目标和bare Git远端实跑：合并模板保留专有行；knowledge-update实际读取且空采用范围无需安装；默认路径和检查模式不写Git；显式写入选定文件后提交、推送和独立检出回读；同输入复跑无新提交；双方偏离旧基线产生冲突，目标人工内容不覆盖；原工作树、暂存文件及索引快照保留。组织开关关闭，即使有清单也未执行。此测试使用固定本地正式模板替身，不是实时Workspace网络拉取验收。

模型隔离调用实际读取技能并生成执行脚本，但180秒时限结束，没有完整最终回复，不记模型整轮通过。测试脚本先后暴露状态字符串空格及git status可选索引缓存写入问题，保留失败，修正测试断言并仅在测试进程使用GIT_OPTIONAL_LOCKS=0后四场景通过。没有修改技能以掩盖失败。

这是Agent指导下的隔离Git执行证据，不是通用同步程序或平台私有性检测已实现。真实私有属性、认证、分支保护和组织PR分发仍在实际部署时核对。本轮没有写真实私有仓、组织分发、个人资料、定时任务或业务数据。

第一阶段保留workspace-update兼容入口；每日通用定义改接workspace-sync，真实每日任务和组织消费者由协调方接续，取得两处迁移回读前不删除旧正式技能或安装版。
