# 对话技能入口

本次统一正式名称；实际安装与宿主加载状态由各使用者核对。对话能力每项只保留一个正式调用名，统一采用 conversation 前缀。

| **入口** | **职责** |
| --- | --- |
| [对话管理 conversation-management](../skills/conversation-management/SKILL.md) | 对话归属、可用工具及能力衔接 |
| [对话回顾 conversation-review](../skills/conversation-review/SKILL.md) | 依据已有公开记录解释决定、纠正和未完 |
| [对话归档 conversation-archive](../skills/conversation-archive/SKILL.md) | 保存可追溯原文并核对增量 |
| [对话恢复 conversation-resume](../skills/conversation-resume/SKILL.md) | 按授权、状态和断点接续任务 |
| [对话刷新 conversation-refresh](../skills/conversation-refresh/SKILL.md) | 目标对话重读适用工作区规则 |

通用回顾可以使用明确提供的公开 Markdown 或文本，按实际完整性说明缺口。用户要求保存这类材料时，保留所给原文件，回顾另存；这不代表取得宿主完整原始导出。随包原始记录读取和已验证的结构化增量归档路径目前针对 Codex JSONL，项目／侧栏调整及跨对话消息依赖实际可用的原生工具。通用命名不是其他平台适配已经完成的证据。

conversation-archive 复用同级完整 conversation-review 的原始记录准备接口；安装时保留两包及其引用、脚本。独立位置的依赖参数和读取命令以[当前归档说明](../skills/conversation-archive/references/README_zh.md)为准，不能用回顾摘要代替完整记录。恢复与刷新相互独立，规则刷新不自动恢复被暂停的业务。

旧名 codex-conversation-management、codex-conversation-review、codex-conversation-archive、resume-chat、refresh-chat 及更早 resume-interrupted-chat 只在迁移和历史记录中保留，不作为第二份活跃技能。替换时先保留个人修改，再核对完整包和调用引用。
