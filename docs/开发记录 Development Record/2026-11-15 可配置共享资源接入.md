# 可配置共享资源接入

## 变更

新增通用目录资源接入工具，外部 JSON 定义任意资源名及目录，各仓库独立配置链接入口和资源子集。路径以配置文件为基准，不推断公司目录、仓库分组或固定资源类型。

保留默认预览和显式执行，先检查全部选定映射，再按真实状态创建或复用链接。拒绝实体占用、错误或损坏链接、Git 跟踪内容、越界或重叠映射及转向父目录。资源仅在明确允许时新建，正确链接及忽略规则重跑复用，中断保留已完成部分。

knowledge 保留通用实现、中英文说明和通用/研发两份配置案例。Workspace 的研发模板采用可选示例并预留项目实际配置与消费者字段，不把研发案例写成所有项目的强制目录。旧初始化器和真实资源未改。

## 依据和验证

相关机制、职责、源码映射分别维护在共享资源的通用调研、架构设计和代码结构设计，后续工作在原开发计划续写。两组临时仓库的真实链接、重跑、冲突和中断验证见 [运行记录](<../运行记录 Run Record/2026-11-15 可配置共享资源接入验证.md>)。

本轮未新增独立 Skill，没有自动扫描或迁移生产数据。跨平台、真实消费者和迁移仍需分别确认及验证。发布范围为通用工具、说明、示例和验证记录，个人配置与真实数据保留在运行环境。
