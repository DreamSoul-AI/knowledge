# 跨对话工作留言发布

## 改动

为既有 [AI Work Message](../../skills/ai-work-message/SKILL.md) 增加手动跨对话盘点，不另建技能或定时任务。技能说明、显示摘要、中英文指南与首页用途同步更新，详细流程独立放在 [global-review.md](../../skills/ai-work-message/references/global-review.md)。

新一轮先确认具体起止时间和来源范围，读取实际对话记录并按事项归并。先输出按推送建议、完成状态和任务细则分层的工作汇总，再与本人校准并一次准备全部选定目标板的正文。是否已完成和是否适合分享分别判断，阶段成果不自动推荐通报，也不为每个板凑留言。

固定历史截止点，区分当时的交付与后来更新的材料。重复事项按目标板分别核对，保留失败、暂缓、未知和撤回状态。恢复登录、补一个受众版本和确认正文均不自动扩大正在试写的执行范围；仍适用的明确发布授权不重复询问。

## 范围

本次只发布AI Work Message及入口、指南和专用记录。Agent实验执行、日志总表对账、研究样例、个人配置和原始对话证据不包含在提交中。真实留言板、定时任务、Workspace模板和其他技能不因这次发布而修改。

本地模拟验证不是生产写入器，当前技能通过宿主实际可用的历史、文档工具执行。工具不可用、正文无法取得和时间无法精确核对时说明覆盖限制，不承诺所有平台自动接入。

验证依据见 [运行记录](<../运行记录 Run Record/2026-11-20 跨对话工作留言发布验证.md>)。
