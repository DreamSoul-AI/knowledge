# 网站静态发布 Skill 迁移说明

记录范围：2026-11-16—17。维护分支：`feature/migrate-website-static-publish`。当前为 1.2.0 迁移候选版本，待合并发布。

## 维护来源与主要调整

`website-static-publish` 从 website-deployment 迁入 knowledge，后续技能维护以[当前 Skill](../../skills/website-static-publish/SKILL.md)为准。原项目保留部署案例、设计资料、历史证据和迁移前快照。

- 默认目标设为 `china`，使用 ESA；ESA 与 Cloudflare 默认分别通过官方 ESA CLI、Wrangler 发布。配置格式保持 `schemaVersion: 2`，升级保留用户已有配置。
- 增加 ESA OAuth 接续脚本：通过阿里云 CLI 核对身份、刷新凭据，将临时凭据传给 ESA 子进程，并处理环境隔离、秘密过滤、失败与超时。
- 补齐中英文安装、配置、首次发布、同址更新和验收流程，简化常用命令；主入口聚焦 ESA 和 Cloudflare，短时测试链接规则明确归属 ESA。EdgeOne 从主入口的交付要求和验证列表移出，兼容流程集中在配置规则与专项参考，仅在明确指定或旧配置选中时加载。
- 按技能库结构整理目录：模板归入 `assets/`，指南归入 `references/`，执行脚本与测试同放 `scripts/`；根忽略规则为随包脚本保留精确例外。中英文仓库入口位于 CPU 清理技能之后。

## 分发与配置

源码使用仓库根许可证，独立安装或打包时将其复制到 Skill 根目录。配置模板为 `assets/CONFIG.example.md`，使用者在 Skill 根目录创建自己的 `CONFIG.md`；该文件由技能内 `.gitignore` 忽略。真实账号、凭据、站点产物、厂商 CLI 包和验证临时材料不进入分发内容。

迁移期间曾在 CLI 验证后更新本机安装至 1.2.0，并按授权切换 ESA 默认方式；后续目录与指南整理尚未同步到该安装。首次配置与升级步骤见[中文指南](../../skills/website-static-publish/references/README_zh.md)和[English guide](../../skills/website-static-publish/references/README.md)。
