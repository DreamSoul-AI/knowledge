# 工作留言重点与实验执行

## 工作留言

核对现有技能与适用留言板规范后，保留已覆盖的首次交付精炼、真实入口、逐板语境和用户同文定稿规则。本轮在 [AI Work Message](../../skills/ai-work-message/SKILL.md) 及中英文指南补充适度突出关键行动、真实期限、结论和必要入口；发布回读同时检查加粗与链接。

技能更新通知保留所属仓库入口，条目以带正式链接的技能名作加粗引导，一句话说明用途及必要变化。正式入口为 `SKILL.md` 时直接链接该文件。初次试跑仍将技能名称放到句末，定向修订后用相同输入、新会话复测，输出符合预期；不能据单次输出认定所有留言都稳定符合要求。

规范已有的项目专有格式继续由项目维护，没有修改 Workspace 模板、真实留言板或其权限。

## Codex 实验执行

新增 [Codex 实验执行](../../skills/codex-experiment/SKILL.md)，将验证问题转成最小可观察实验，自主准备、运行、核验和解释。直接探测、比较和独立测试会话按问题选择，简单验证直接交付，需要复跑时再留记录和脚本。

复用已有项目机制实验中的隔离输入、明确启动条件、实际产物核验，以及 CLI 与桌面分开取证的方法。未搬入私人材料，也未将 Windows 单次排障变成通用要求。入口保留核心流程，条件性 CLI、App Server、隔离和取证细节放在执行参考，中英文指南提供使用入口。

两项技能的真实 CLI 验证及未覆盖范围见 [运行记录](<../运行记录 Run Record/2026-11-19 工作留言与实验执行验证.md>)。根中英文首页增加新技能入口，其他技能、本地既有调研样例和定时任务保持原范围。
