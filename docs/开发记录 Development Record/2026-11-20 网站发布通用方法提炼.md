# 网站发布通用方法提炼

2026-11-20 按用户确认，将 website-deployment 项目的多来源静态站点组装、旧域名迁移、ESA 续订检查三项通用方法提炼到公开网站部署技能。网站代码、具体来源清单、业务数据与原始回执继续留在来源项目。

## 改动与采用范围

- 在[主入口](../../skills/public-website-deployment/SKILL.md#共用产物流程)和 [ESA 参考](../../skills/public-website-deployment/references/esa.md#选择发布入口)增加条件入口，详细方法集中在[多来源静态站点组装](../../skills/public-website-deployment/references/multi-source-sites.md)。
- 补充固定来源版本与公开文件摘要、目标路径映射、链接适配、输入与输出摘要分开记录、单专题更新时保留完整站点及发布后验收。
- 增加 [ESA 旧域名迁移](../../skills/public-website-deployment/references/esa-domain-migration.md)：新站先验收、按旧主机逐页映射、保留参数与浏览器片段、保留旧 DNS 和证书，说明永久跳转缓存对恢复的影响。
- 增加 [ESA 订阅与续订检查](../../skills/public-website-deployment/references/esa-renewal.md)：区分计算订阅与站点套餐，按实例和费用条件设置，再独立回读；配置成功不等于未来实际续订成功。
- 同步[中文指南](../../skills/public-website-deployment/references/README_zh.md)与[英文指南](../../skills/public-website-deployment/references/README.md)的请求示例和证据范围。2026-11-20 案例支持 ESA 首次合并发布，不据此标记单专题后续更新、Cloudflare 组合发布或真实恢复已经通过。
- 现有发布脚本、配置格式和默认行为保持不变，未引入通用组装脚本、特定站点路径或业务数据断言。迁移和续订为按请求使用的独立流程，普通上传不会自动执行。
- 根中英文 README、技能描述与研发导航同步三项入口。新文档沿用中文详细参考、中英文使用指南的现有组织方式。

## 安装与功能复核

更新前备份原安装，保留私人 `CONFIG.md`。安装采用本工作分支的完整公开技能目录，逐文件摘要核对安装与源码一致；网站代码及全部新旧原始回执仍留在 website-deployment。

通过安装后的身份与凭据隔离测试、官方 CLI 只读项目查询、固定来源重新组装、线上产物及旧域名跳转检查，并回读计算订阅、站点套餐与自动续订状态。本次复核发现两点实际使用条件，已补入续订参考：

- 私人配置允许站点字段为空，查询时先从目标项目的实际域名绑定解析站点，不向 API 传入空值，也不改写私人默认值。
- 阿里云 CLI 3.5.3 未登记计算订阅查询接口时，显式指定已验证的 API 版本和官方端点，使用 `--force` 跳过本地元数据校验。普通调用失败与修正后的成功回执均保留。

本次没有改动发布脚本或配置格式。实际功能、失败经过与未覆盖范围见运行记录。提交前已读取多人协作代码开发规范第 25 版中分支、提交、推送与合并相关正文，本轮按用户限定保留工作分支供后续审阅。
