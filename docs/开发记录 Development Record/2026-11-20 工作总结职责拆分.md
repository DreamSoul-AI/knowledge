# 工作总结职责拆分

本轮将工作留言中的跨对话来源收集和事实盘点抽为 `work-summary`，保留独立的完整总结。工作留言接收总结，负责分享筛选、受众校准、逐板成文及授权交付。

- 工作总结保留已收尾、未收尾和待核事项，包含不适合分享的工作；每轮全局盘点确认具体时间和来源。
- 工作留言复用上游范围和证据，只补查变化和缺口；单次沟通仍可直接成文。
- 同步两项技能的中英文指南、元数据和首页入口。既有发布、回读、撤回及日期规则保留。

首版使用既有材料验证两项技能的职责和交接。Agent 实验执行和日志对账是独立工作，未纳入本次调整。
