# 收尾技能与总结留言核对

本记录保存本轮发布前的制作与审阅范围；验证是在本地进行，没有对真实工作对话或业务平台写入。

新增[收尾 wrap-up](../../skills/wrap-up/SKILL.md)，分别核对各对话本轮结果、剩余事项、能否停和下次入口。只有明确要求时再组合多个对话，不把全局盘点、日志、留言、归档或发布强加为前置条件。

[工作总结 work-summary](../../skills/work-summary/SKILL.md)补交付前的来源对照及操作例子，保留未完成项目中的独立成果。用户指出遗漏后检查同类问题，不机械按举例顺序组织文章。

[工作留言 work-message](../../skills/work-message/SKILL.md)在入口限定旧轮临时简版、删项和排序的范围；保留事实、定稿、个人配置及有效权限边界，遵守本次明确的简写要求。配套双语说明同步调整。

范围不含旧轮撤回的整套试改、权限与时间规则、真实留言发布或其他暂放工作。验证见[运行记录](<../运行记录 Run Record/2026-11-24 收尾与总结留言行为验证.md>)。
