# 工作留言分享核验

## 调整

`ai-work-message` 默认结合实际接收者、资料直接授权、用户组和继承关系核验引用入口，不把本人可读、链接设置或岗位名称当作完整依据。已有证据自动核对，无法确认的入口说明具体缺口；实际授权与明确披露范围冲突时再请使用者决定，不自行改变权限。

多板简要版压缩表述，保留适用且可读的事项和链接，不凭岗位或板名删项。中英文指南与批量成文参考同步，未引入新的场景分类或独立技能。

## 边界

只修订工作留言及其配套说明，`work-summary` 的原始盘点职责不变。本机旧留言版本需随正式发布同步；工作总结作为既有正式依赖按需安装。未完成的代码设计、代码分析、日志对账和其他首页草案留本地，真实用户配置与授权回执不随仓库分发。
