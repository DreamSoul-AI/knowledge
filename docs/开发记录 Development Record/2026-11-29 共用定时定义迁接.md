# 共用定时定义迁接

会议总结、电子邮件总结和工作区同步改用按用途命名的 scheduled-* 定义。频率、执行时刻与业务时区由部署者配置，示例不启用调度，也不固化每日或个人运行时间。

会议和邮件保留增量接续，新增可选 reporting.period: natural_day：按本次计划触发上下文及业务时区，固定前一个自然日的排他窗口。执行延迟不更改归属，人工明确日期优先；补漏与晚到材料沿原成功游标、回看及未完项处理，不重建状态。工作区同步继续复用 workspace-sync / knowledge-update 及已实现的可选私有 Git、组织分发，刷新接正式 conversation-refresh。

旧 daily-* 提示词和指南保留短转接，不另设活跃任务或复制生产配置；旧示例配置由新目录单一入口接替。真实任务先确认新文件可读，再由部署方修改原引用并回读，保持身份、配置和进度。仓库发布不等于任务已迁移或已运行。
