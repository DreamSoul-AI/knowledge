# GitHub汇总临时目录排除

**本记录保存发布前补齐.tmp默认排除及实际排除说明的改动。** 正式采用以发布固定提交和安装回执为准；本轮不重跑组织范围盘点，不修改来源仓库或正式Learnings。

原脚本已排除tmp、temp，但遗漏当前采用的.tmp。补齐后，普通.tmp历史快照不作为当前经验来源；登记在其中的独立worktree仍从各自登记根扫描。

保留优先级：显式source-path可越过默认目录排除，显式exclude仍优先。没有新增output通用禁令，项目可按实际用途用调用参数排除。

返回结果新增exclusions明细，last-run.json继续保留实际scope、路径及原因，intake.md增加“本轮排除”。coverage同时记录默认目录组成部分及本次显式排除配置；完整性仍指该范围内的扫描，不冒充已读排除内容。远端manifest的范围级排除无需新增文件路径字段。

文件范围为[接收脚本](../../skills/github-summary/scripts/github_summary.py)、[针对性测试](../../skills/github-summary/tests/test_intake.py)、[技能入口](../../skills/github-summary/SKILL.md)、双语说明和引用规范。其他技能与个人分支改动保持独立。实际验证见[运行记录](<../运行记录 Run Record/2026-11-24 GitHub汇总排除验证.md>)。
