# 调研范围与能力衔接

general-search 按用途和证据需求判断正式课题范围，保留局部问题的轻量回答。对象与机制先解释再比较，导读短表不承担长篇说明，关系图先确定语义再选布局。分阶段交付不缩减总范围，首稿仍须有实际解释深度。

document-sync 的飞书入口接入已有 lark-auth-reuse。本轮同运行环境的有效核验可复用，认证异常先区分执行环境、用户授权、应用权限和资源访问，必要登录继续沿 lark-shared。没有修改同步算法、登录实现或凭据管理。

新增 learnings 单文件技能，接续已有两稿的来源接收、过程回看、分类积累、去重和采用清理。各类平台操作复用已有能力，经验接收不自动产生实施或发布授权。

每日会议总结提示词只增加读取使用者 USER 技能配置的通用入口。个人交付偏好、位置和权限继续留在使用者配置，不改既有任务或调度。
