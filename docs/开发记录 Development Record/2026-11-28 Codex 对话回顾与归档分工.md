# Codex 对话回顾与归档分工

新增 codex-conversation-review，负责指定对话定位、公开原始记录读取、固定截止与分页，以及流程、决定、纠正和未完事项的回顾。整体回顾读完整指定范围，默认在对话回答，不导出全账号内容或读取隐藏推理。

原 archive 的记录解析、时间依据及回顾组织迁入 review，archive 调用该完整记录准备接口，继续负责原话、工具、时间的不可变归档、字符/顺序/重复核验与增量。保留原 CLI、Python 辅助入口及档案格式，不维护第二份解析器。新增 --review-skill 支持独立依赖位置。

两个完整目录默认同级安装。归档 ZIP 同时包含两包，双语首页与指南说明依赖。review 可单独使用，缺依赖的 archive 明确失败，不自动回退旧解析器。脚本不自动生成语义回顾，Agent 仍须实际阅读和整理。

本轮不包括其他技能、自动化、个人配置或业务原文，真实会话和归档验证材料保留本机。验证范围见 [运行记录](<../../docs/运行记录 Run Record/2026-11-28 对话回顾归档验证.md>)。
