# 中断恢复更名

中断恢复技能正式标识由 `resume-interrupted-chat` 调整为 `resume-chat`。本轮只改名称和路径，原有恢复判断、授权、消息选择、只读筛选脚本及验证边界保持。

- [新入口](../../skills/resume-chat/SKILL.md)：目录、SKILL的name、界面显示名、默认调用和双语说明统一采用resume-chat
- 双语首页及安装迁移说明使用新入口，Git忽略例外跟随脚本新位置
- 历史发布记录仍保留旧名，链接固定到当时提交，避免把历史事实改写成当时已经使用新名
- 安装迁移保留有效个人改动及额外文件，只保留一份可发现的技能入口，不新增旧名SKILL别名

名称和入口一致性、相对链接及包结构已检查。筛选脚本与原发布版本字节相同，主流程正文除标识替换外相同；复用既有行为验证，不为纯更名重做整套实验。论文入库和其他技能未修改。
