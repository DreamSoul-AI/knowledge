# GitHub 汇总与首页分类

## 本轮调整

GitHub 汇总明确为六步：确定范围和规范、盘点固定版本、接收原文并归并经验、检查仓库、展示结果、按授权收尾。每一步说明读取和写入范围，区分临时接收、正式 Learnings、来源正文和远端修改。公司或个人要求通过外部规范输入，不写进通用技能。

报告先给便于扫读的总体结果：提交和合并、PR、Actions 用量及计费、Learnings 收获及待处理项，再按仓库展开关键变化。提交注明比较区间并去重，用量和计费同项展示但分别依据实际返回；仓库数字不能代替经验归并。

双语首页按工作整理、调研研究和研发运行分类，保持正式技能顺序一致、用途短句及现有安装链接。独立工具中的重复入口按真实身份核对，Grok Bot CLI 保留一个工具条目，技能入口独立保留。

## 范围与保留

本轮仅涉及 GitHub 汇总技能、双语首页及本轮必要记录；接收脚本和既有测试未修改。其他技能的显示名调整、本地代码设计／代码分析和日志对账草案均不纳入。首页中此前未发布的草案说明和另行命名建议保留本地，不随分类改动发布。

来源原件、机器配置、公司规则输入、API 原始回执及任务脚本留在本地任务目录；不写入分发技能或本记录。

## 验证

有限真实仓库检查、原文接续和恢复、两项失效登记清理的结果见[运行记录](<../运行记录 Run Record/2026-11-23 GitHub 汇总与首页分类验证.md>)。远端正式发布及安装状态以对应 PR 和收尾回执为准，不用本地验证代替发布完成。

## 命名校正

用户进一步明确正式英文名沿用既有标识，用小写和连字符。要求写入 REPO.md，18 个正式技能的显示名及双语首页、独立工具和外部技能入口按该口径核对；中文说明保留，英文部分如 `work-summary`、`github-summary`、`grok-bot-cli` 不再使用另起的标题式写法。目录、调用名、技能能力、其他元数据及未发布草案不变。17 个技能需要调整显示名，另一个已符合。
