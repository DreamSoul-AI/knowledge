# 定时任务定义与共享资源范围

## 当前变更

把既有每日会议总结整理为可复用任务定义，提示词每轮读取实际项目配置并组合 Calendar Meeting Archive、Meeting Minutes 和 Document Sync。账号、目录、规范、状态和授权由外部配置提供，安装任务包不注册调度。新增中英文任务总表和指南，分别维护定义状态与实际验证范围。

手动运行沿用原正式稿、回执和状态，以真实来源及在线云端内容判断复用和阻塞。没有需要新生成的材料时复用既有成果，未为验证创建副本。所测流程及未触发分支见 [运行记录](<../运行记录 Run Record/2026-11-15 定时任务与共享资源验证.md>)。

多仓库共享资源接入继续作为候选，维护 [开发计划](<../开发 Development/开发计划 Development Plan 多仓库共享资源接入.md>)。核心是多个仓库通过符号链接复用部分资源，输入不能绑定个人路径、平台或固定资源类别。既有工具经过隔离接入及换布局测试，任意映射、迁移和其他平台仍留待实现或验证，未新增独立技能。

## 版本和发布边界

本轮未修改技能源码。发布分支从 dev 建立，并合入 main 已发布内容，防止分支差异让 Literature Search 回退。发布前核对最终相对 main 的技能目录无差异，实际安装的三个会议技能与仓库版本一致。

Research Plan 的规范、大纲和模板在所属 workspace 仓库单独提交并发布，未放入 knowledge 的技能目录或混入 Workspace 其他未完成修改。个人配置、真实会议证据及临时核验脚本不随本包发布。原定时安排保持不变。
