# 工作留言重点与交付回报

本轮只更新 [工作留言 AI Work Message](../../skills/ai-work-message/SKILL.md) 及中英文指南、发布参考，保留已有的事实边界、逐板语境、真实入口和用户定稿规则。

- 重点加粗按读者需要选择，每条留言通常集中在一两个核心重点，优先突出希望读者点击的主要成果或行动入口。大纲、沟通流程等通常保留普通链接，其本身为本次重点时再强调
- 技能更新保留仓库及正式技能入口，简短说明用途和必要变化，取消“所有技能条目都加粗”的要求
- 无论是否上传，都在当前对话展示最终留言正文。已写入时展示回读确认的实际稿，并说明目标位置和各板状态；多板同文只展示一次，不同正文分别展示

最初的合成留言试跑已验证真实技能入口和只展示不写板；后续用户将强调范围收敛为上述规则，旧试跑不作为新规则的行为验证。本轮通过技能校验、Markdown 解析和差异复核，没有发送真实留言。

Codex 实验执行按最新要求撤出本轮待合入范围，技能、原始验证及原先两项合并记录保留本地待调整；不安装、不合并或发布该技能。既有远端提交历史未重写，本轮 PR 的当前差异只保留工作留言。
