# Figma Design 名称同步

按用户确认，将外部维护的技能统一命名为 Figma 设计 Figma Design，调用名为 `figma-design`。本仓同步中英文技能目录、源码入口与完整安装说明，源码和安装包仍由 [Figma 仓库](https://github.com/DreamSoul-AI/figma)维护，不在本仓复制一份。

Figma 正式源码通过 [PR #17](https://github.com/DreamSoul-AI/figma/pull/17) 接入 dev，再经 [PR #18](https://github.com/DreamSoul-AI/figma/pull/18) 合入 main。新名安装包为 [Figma Design v1.0.1](https://github.com/DreamSoul-AI/figma/releases/tag/figma-design-v1.0.1)。旧安装先保留个人修改再替换，避免同时发现两个名称；历史实验名称、旧包与原有证据保持可追溯。

本轮未发布 Figma 原工作区的其他未提交功能及实验改动。knowledge 的本地 Codex 实验执行草稿和调研样例不在提交范围。核对见[运行记录](<../运行记录 Run Record/2026-11-19 Figma Design 名称核对.md>)。
