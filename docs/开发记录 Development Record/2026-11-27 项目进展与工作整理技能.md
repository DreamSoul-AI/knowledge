# 项目进展与工作整理技能

本轮接续已验证的本地候选，发布范围为四个完整技能包。

- [project-progress-sync](../../skills/project-progress-sync/SKILL.md)：接续原本地日志与总表对账候选，区分核对和已授权同步。新增前查重，写前读取最新目标，按局部差异写入并回读，保留人工更新。旧候选未曾正式分发，不保留第二个可发现入口。
- [work-message](../../skills/work-message/SKILL.md)：结合目标板前文、接收者处理责任、时限及依赖选择标签，共有内容尽量保持一致。收到反馈后复核相关整批稿，内部筛选理由与面向读者的正文分开。列表修改按真实评论、定位和资源依赖保护，不把块ID不变扩大为绝对限制。
- [work-summary](../../skills/work-summary/SKILL.md)：按读者工作结构组织部门和项目，在项目内保留独立成果和未完状态。事实反馈回查相应依据，单纯沟通取舍不改变工作事实。接入已验证的独立来源分工，主代理统一覆盖核对与去重。
- [general-search](../../skills/general-search/SKILL.md)：正式首稿解释核心对象、代表场景、状态和完成证据，在共同前提下比较路线和边界，避免停在索引式概括。

同步维护受影响的双语说明与首页导航。平台规则、项目要求、个人配置及真实业务来源仍由使用环境接入，不随技能包分发。没有新增上层空技能、固定公司清单、定时安排或个人技能改动。

有限验证及未覆盖范围见[运行记录](<../运行记录 Run Record/2026-11-27 四技能有限验证.md>)。安装与发布状态以实际固定版本和使用者回执为准，不由本文件代替。

后续小改：work-summary在另有日志更新要求时，先定位对应使用者实际日志，读取近期写法和状态后只补授权差异。明确指定优先，其次读取该使用者USER入口及索引；普通总结不强制扫描日志。
