# 每日电子邮件总结发布

新增[每日电子邮件总结](https://github.com/DreamSoul-AI/knowledge/blob/f3df591a2f9c01296f191aae7ea2018b68479873/automations/daily-email-summary/README_zh.md)首版任务定义，包含提示词、外部配置示例和中英文指南。根目录及 automations 中英文总表提供统一入口。

摘要按用户确认采用「主题或发件方｜下一步行动或当前状态」，随后说明具体问题、变化、已处理内容、等待对象、期限及真实链接。研究通知保留实质反馈，合并往来不只统计通知数量。写法通常约3至6项，按实际价值选择，不要求每项都有新待办。

平台、连接、预期账号、文件夹、时区、兴趣及输出由使用者配置。指南说明身份与文件夹核对、固定窗口试跑、实际调度环境对文件和连接的要求。默认不保留原邮件或来源清单，手动预览不推进生产进度，也不授权邮箱写操作。

本次仅发布邮件总结任务定义。私人配置、真实邮件及样例不分发，其他本地草稿保持原状。既有定时任务不修改，不新建调度。验证范围见[运行记录](<../运行记录 Run Record/2026-11-20 每日电子邮件总结验证.md>)。
